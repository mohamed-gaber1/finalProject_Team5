# finalProject_Team5

Team 5 final project: an e-commerce backend API built with Node.js, Express and MongoDB.

## Features
- JWT authentication and user management
- Products, orders and wishlist
- Contact messages endpoint
- Request validation

## Tech stack
Node.js, Express 5, MongoDB (Mongoose), JWT

## Getting started
```bash
npm install
npm run run:dev
```
Create a `.env` file with your MongoDB URI and JWT secret. API collections are in the `postman/` folder.
